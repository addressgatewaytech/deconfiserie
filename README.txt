DE CONFISERIE – deconfiserie.qa  (static website, no database)

UPLOAD
1. Upload everything in this folder to your hosting's website root (public_html).
2. Point deconfiserie.qa DNS to the hosting and enable free SSL (https).
3. Submit https://deconfiserie.qa/sitemap.xml in Google Search Console.

ADMIN  –  https://deconfiserie.qa/admin.html
Default password: Confiserie@2026  -> change it in "Publish & Settings" (paste the code into assets/js/config.js).
- Products: add / edit / hide / delete, upload photos (auto-compressed).
- Publish: "Download website update (.zip)" -> upload & extract in website root (overwrite).
- Sales: record orders or "Paste WhatsApp order" to auto-fill from the customer's message.
- Dashboard: revenue, orders, average order, top cakes. Sales data stays in your browser –
  download a backup weekly (Publish & Settings > Sales data backup).

SETTINGS  –  assets/js/config.js
Phone, WhatsApp, email, CR No., e-commerce licence no. (shown in footer/About once filled), delivery note.

NOTE: The admin password is a light gate only (no server). Legal pages are standard templates –
have them reviewed before launch.
